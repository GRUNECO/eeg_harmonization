# misc

Historical scripts and notebooks from earlier analyses of the group (ComBat / neuroHarmonize variants per study, BIDS conversion rules, dataset download helpers, plotting snippets). They are kept for reference and are **not** part of the `sovaharmony` pipeline described in the main README. Paths inside them point to the original authors' machines.

- `reglas_bids/`: BIDS conversion rules (YAML) used for each database.
- `neuroharmonaze*.py`, `COMBAT/`: ComBat harmonization of feature tables (the version used in the PSEN1 low-density study is in the `eeg-psen1-classification` repository).
